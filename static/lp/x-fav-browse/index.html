X のいいねから、好きなものだけ。

気ままに眺める。

好きで集めたイラストや写真を、

なんとなく開いて、また「好き」に出会う。

App Store で入手↗

無料でインストール。iPhone でいいねを取り込めます。

ちょっとした空き時間に。

探すものがなくても、
眺めたいものはある。

あの絵の色づかい。かわいい動物。心に残った風景。
自分がいいねしたものだから、眺めているだけで楽しい。
忘れていたお気に入りも、ふと目に入ってきます。

気になった一枚から。

「これも好きかも」が、
次の一枚へ。

画像をタップすると、AI が見た目の似た投稿を表示。
お気に入りを眺めながら、似た雰囲気の画像へと気ままに回れます。

画像・動画・テキストをまとめて見返せる、自分専用のプライベートなギャラリーです。

まずは、いまのいいねから。

取り込んだら、あとは眺めるだけ。

  1. 01 / はじめる

    アプリを入れる

    iPhone に Refav Gallery をインストール。

  2. 02 / 取り込む

    いいねをスクロール

    アプリで X にログイン。「いいね」や「ブックマーク」をスクロールすると、表示された分が取り込まれます。

  3. 03 / 楽しむ

    好きなものを眺める

    ギャラリーを開いて、気になる画像をタップ。空き時間に、気ままに楽しめます。

PC では Chrome 拡張機能で X のいいねを取り込み、Web 版で閲覧できます。Android では、PC で取り込んだいいねを Web 版で楽しめます。

気になること

無料で始められますか？

無料でインストール・登録して始められます。利用条件や追加プランは、アプリ内でご確認ください。

画像以外も見返せますか？

画像だけでなく、動画やテキストの投稿にも対応しています。

iPhone だけで取り込めますか？

はい。アプリ内で X にログインし、いいねやブックマークをスクロールして取り込めます。
