あの日のいいねに、もう一度。

また出会う。

「これ、好きでいいねしたんだった。」

いいねした、そのあとに。

覚えていないだけで、
好きなものは、まだそこにある。

流れてきた作品にいいねして、そのまま次の投稿へ。
見返さないまま埋もれた中にも、もう一度見たい一枚はあるはず。
Refav Gallery は、取り込んだいいねを眺めながら、
そんな一枚と再会するための場所です。

探す言葉がなくても。

何をいいねしたか、
思い出さなくていい。

作品名も、作者も、いつ見たかも。
覚えていなくても、取り込んだ画像を一覧で眺めれば、気になる一枚がふと目に入ります。

ギャラリーの「今日のセレクション」は毎日並びが変わるので、過去のお気に入りを見返すきっかけに。

再発見できるのは、Refav に取り込んだ投稿です。過去のいいねが自動ですべて復元されるわけではありません。

再会した一枚から、もう少し。

「やっぱり好き」が、
次の再発見につながる。

気になった画像を開くと、AI が見た目の似た投稿を表示。取り込んだお気に入りの中を、雰囲気をたどって巡れます。

一枚との再会をきっかけに、ほかの「好き」も思い出す。そんな寄り道も楽しめます。

まずは、あなたのいいねを。

取り込んだ「好き」が、再発見の入り口に。

  1. 01 / はじめる

    アプリを入れる

    iPhone に Refav Gallery をインストール。

  2. 02 / 取り込む

    いいねをスクロール

    アプリで X にログイン。「いいね」や「ブックマーク」をスクロールすると、表示された分が取り込まれます。

  3. 03 / 楽しむ

    忘れていた一枚と再会

    ギャラリーを開いて、気になる一枚へ。探すものが決まっていなくても、気ままに眺められます。

PC では Chrome 拡張機能で X のいいねを取り込み、Web 版で閲覧できます。Android では、PC で取り込んだいいねを Web 版で楽しめます。

気になること

昔のいいねが全部、自動で出てきますか？

いいえ。ギャラリーに表示されるのは、Refav に取り込んだ投稿です。X のいいねやブックマークをスクロールして、表示された分を取り込みます。X 上で表示・取得できない投稿の復元を保証するものではありません。

無料で始められますか？

無料でインストール・登録して始められます。利用条件や追加プランは、アプリ内でご確認ください。

画像以外も見返せますか？

画像だけでなく、動画やテキストの投稿にも対応しています。

iPhone だけで取り込めますか？

はい。アプリ内で X にログインし、いいねやブックマークをスクロールして取り込めます。
